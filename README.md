# 萌寵大賽跑 Pet Dash 3D

冬菇（紅貴賓）、墨墨（英短）、粉粉（美短）的立體賽跑網頁遊戲。玩家選一隻角色操作，另外兩隻由電腦控制。三隻一起衝向 1500 米外的終點，最先衝線者勝出。

## 開啟方法

遊戲使用 ES 模組，必須經網頁伺服器開啟（直接雙擊不能運行）。

- **GitHub Pages（建議）**：在倉庫 *Settings → Pages* 選擇 `main` 分支的根目錄，即可得到一個網址分享給別人玩。
- **本機**：在倉庫根目錄執行 `python3 -m http.server 8000`，然後開啟 `http://localhost:8000/`。

Three.js 已放在 `lib/`（MIT 授權），不需要連接網絡。

## 玩法

| 動作 | 電腦 | 手機／平板 |
|---|---|---|
| 左右移動 | ← → 或 A D | 畫面下方 ◀ ▶ |
| 跳躍 | 空白鍵、↑ 或 W | 「跳」按鈕 |
| 暫停 | Esc 或 P | 右上角 ⏸ |

- 🍖🐟🍩🍓 **食物**：吃下即時加速。連續吃不被撞可累積 COMBO（最多 ×5）。
- 🌈 **彩虹加速板**：踩上去短暫加速。
- ⚠️ **障礙物**：三角錐、欄架、石頭可以跳過；木箱堆和滾動的大球太高，只能避開；泥漿會令你減速。
- 撞到障礙物會暈眩減速，並扣分。
- 分數 = 跑過的距離 + 食物 + 漂亮跳躍 + 名次獎勵 + 時間獎勵。最高分會儲存在瀏覽器。

## 角色

| 角色 | 特點 |
|---|---|
| 冬菇（紅貴賓） | 跳得最高，各方面平均 |
| 墨墨（英短） | 最高速度和加速倍數最高，但轉彎較慢 |
| 粉粉（美短） | 起步加速最快，轉彎最靈活 |

## 檔案

```
index.html   頁面骨架（選角、HUD、結果畫面）
style.css    介面樣式
models.js    三隻角色的立體骨架模型、多層殼毛髮和動作
scanpet.js   粉粉、墨墨的立體掃描模型：讀取 GLB、骨骼對應和動作
tools/       preview.html：角色近鏡預覽（?view=front|back|side|run|jump）
game.js      Three.js 場景、角色動畫、電腦對手、障礙物、食物、計時計分
audio.js     Web Audio 即時合成：輕快背景音樂、觀眾歡呼和掌聲、音效
lib/         Three.js
assets/      角色圖片（已去除邊緣雜色）、勝利畫面、Game Over 畫面、fenfen.glb／momo.glb（粉粉、墨墨立體模型）
```

賽道上的角色是立體骨架模型（`models.js`）：身體、頭、四肢（髖／膝關節）、耳朵和尾巴各有關節，尾巴是以一串骨骼帶動的蒙皮網格。毛髮用多層殼（shell）技法，同一形狀向外疊十多層，每層只保留部分像素，形成一根根的毛（貴賓狗是一團團捲毛）。跑步（飛奔步法、後腳蹬起露出肉球）、跳躍、轉彎側傾、撞擊暈眩、衝線歡呼和眨眼等動作都由程式驅動。選角畫面、進度條和結果畫面則使用原本的角色圖片。

粉粉、墨墨改用立體掃描模型（`assets/fenfen.glb` 約 0.75 MB、`assets/momo.glb` 約 0.87 MB）：每隻是一個蒙皮網格（約一萬個三角形）加一副四足骨架，動作同樣由程式驅動（`scanpet.js` 的 `SCAN_PETS` 把各模型的骨骼名稱對應到「髖、脊、胸、頸、頭、尾、四肢」）。每隻只需 1 次繪製，比原本的多層殼毛髮（約 80 次繪製、近四十萬個三角形）輕得多。如模型讀取失敗，該角色會自動用回原本的程式模型。
